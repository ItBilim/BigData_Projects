# Тапсыру жинағын ашу және қайта есептеу

Жинақ Windows жүйесінде Python 3.12 ортасында жасалды. Жұмыс қалтасы ретінде жоба түбірін пайдаланыңыз. Бастапқы архивтің бұрынғы кезеңдерде қолданылған орны `D:\BigData\BigData_Projects\cdr_datasets.tar.gz`. Ортақ `experiment.json` іске қосу тізімін көрсетеді. Әр кезең өз параметрлерін тиісті бекітілген конфигурациядан және алдыңғы кезең файлдарынан оқиды. Бұл параметрлерді өзгерту жаңа тәжірибе ретінде тіркелуі керек.

```powershell
python -m pip install -r outputs/stage12_delivery/requirements.txt
python -B outputs/stage12_delivery/run.py
python -B outputs/stage12_delivery/run.py --rerun --from-stage 2
```

Бірінші іске қосу сақталған нәтижелерден тапсыру материалдарын жасайды. `--rerun` көрсетілгенде скрипттер ретімен орындалып, есептер қайта есептеледі. Бұрынғы нәтижелерді салыстыру үшін жоба көшірмесінде қайта іске қосыңыз. Bootstrap қайта есептелгенде жаңа checkpoint жазылады. Бірінші кезеңнің аудиті бұрын жасалған және `outputs/stage1_audit` ішінде. Оны қайта жасауға керек орта өлшемдері мен скрипт туралы сол кезеңнің есебін қараңыз. `delivery_run.log` осы іске қосу кезінде орындалған командалар мен олардың шығысын сақтайды.

## Нәтижелерді оқу

- `stage1_audit` деректер аудитін, деректер сөздігін және ортаны қамтиды.
- `stage2_protocol` бағалау хаттамасын, `stage3_splits` уақыттық бөліністерді қамтиды.
- `stage5_methods` валидацияны, конфигурацияны және таңдалған параметрлерді қамтиды.
- `stage6_scenarios` инъекция журналдары мен хэштерін қамтиды.
- `stage7_leakage`, `stage8_metrics`, `stage9_stability` және `stage10_11_audit` негізгі және қосымша CSV кестелерді қамтиды.
- `figures` мақалаға арналған жеті SVG және 300 dpi PNG нұсқасын қамтиды.
- `article_main_table.csv` негізгі әдіс салыстыруы мен precision интервалдарын береді.

Сынақ жазбалары `scores` ішінде апта және дерек жағдайы бойынша сегіз NPZ файлға бөлінген. `score_manifest.csv` жол және серия санын береді. `score[series_index, row_index]` баллды, `series[series_index]` әдіс пен seed атауын, `subject[row_index]` ішкі кездейсоқ абонент нөмірін, `week` аптаны береді. Дайын инъекциялар үшін `label[row_index]`, синтетикалық инъекциялар үшін `label[series_index, row_index]` қолданылады. Апта кілттерінің реті сақталған. Бірдей баллдардың бастапқы реті де осы ретпен беріледі. Бастапқы телефон идентификаторлары бұл экспортқа кірмейді.

```python
import numpy as np
import pandas as pd

with np.load("outputs/stage12_delivery/scores/stage7_leakage_week32.npz") as data:
    i = 0
    rows = pd.DataFrame({
        "subject": data["subject"],
        "week": data["week"].item(),
        "series": data["series"][i],
        "score": data["score"][i],
        "label": data["label"],
    })
```

Көрнекіліктердегі сенімділік интервалдары негізгі кесте мен тексеру бюджеті графигінде абонент бойынша жұпталған bootstrap есебінен алынған. Апталық, сегменттік және кейінгі дерек графиктері сипаттамалық. Түсім тарихындағы үзік жерлер қолжетімсіз бақылауларды көрсетеді.
